# 已有透明帧的打包工具

`scripts/pack_frames.py` 使用 Python 3.10+ 与 Pillow。它处理已准备好的素材，不包含生成、抠像、运动插值、自动人体分割或游戏接入。

## 输入与命令

输入为一个平铺目录中的小写 `.png` 文件，按文件名自然顺序排列，例如 `frame-2.png` 在 `frame-10.png` 之前。需要相同画布尺寸、有透明像素且非空；RGB/完全不透明图、空帧、混合画布会被拒绝。有 PNG 透明信息的索引图会转换为 RGBA。

```bash
python -m pip install -r requirements.txt
python scripts/pack_frames.py --frames /path/to/source \
  --out /path/to/output/walk-v1 --durations 80 --loop
```

| 参数 | 含义 |
| --- | --- |
| `--frames DIR` | 必填，源透明PNG所在目录 |
| `--out DIR` | 必填，新建或空目录，不能位于源帧目录内 |
| `--durations 80` | 每张源图80ms；默认80ms |
| `--durations 120,40,80` | 按源帧顺序给出完整时长表，必须正整数 |
| `--loop` | 无限循环；省略时单次播放 |
| `--exclude-last` | 明确删除自然排序的最后一张图及其时长，不自动判断重复 |
| `--anchors FILE` | 可选，源画布中的手动锚点映射 |
| `--padding 8` | 联合裁切后的安全边距，默认8px |
| `--preview-scale 2` | 预览整数倍放大，默认2，最近邻；源PNG不缩放 |

若使用 `--exclude-last`，时长表与锚点仍先按**全部输入源帧**提供，脚本随后共同删除末项。生成前必须自己确认末帧确实是重复端点，而不是有意义的过渡。

脚本先在输出目录旁的临时目录写入，成功后移到目标位置；不覆盖非空目录。复做时使用新版本目录。

## 手动锚点

```json
{
  "frame-00.png": [200, 390],
  "frame-01.png": [203, 390],
  "frame-02.png": [199, 390]
}
```

每个值都是对应源画布里的整数像素坐标。它可以是按共同约定标定的躯干中心与地面交点；脚本不判断这个点的解剖或动作意义。提供锚点后，每张图只做整数平移，将各自的锚点对齐到第一张的位置，然后按整组联合可见范围裁切并保留边距与锚点。

不提供锚点时保留源图的共同坐标和有意位移，只做全组共同裁切。源图有抖动也会原样保留。跳跃、前冲等动作不能随意指定逐帧最低点为锚点，否则会消除原本的运动。

这份锚点是**单个公共参考点**，不是逐帧物品握点、脚接触轨迹或骨骼。需要这些数据时另行标定，并按输出 `translation` 进行同一坐标变换。

## 输出

| 文件 | 内容 |
| --- | --- |
| `frames/frame-000.png` 等 | 同尺寸RGBA PNG；动作像素不缩放、不重绘 |
| `sheet.png` | 横向排列的透明精灵图集 |
| `preview.gif` | 浅色底、可直接查看；不保留透明背景 |
| `preview.webp` | 透明无损动画，按预览倍数最近邻放大 |
| `contact.png` | 按帧顺序排列，附帧号和时长的浅底对照图 |
| `animation.json` | 图集尺寸、循环、锚点、源到输出映射、时长和预览信息 |
| `report.json` | 各帧bbox、透明/半透明像素数、不透明像素平均RGB等事实 |

PNG与图集是素材输出；两个动画是预览输出。`--preview-scale` 不改变PNG或图集，只影响两个动画及逐帧对照。

GIF时长取最接近的10ms，最小10ms，记录在 `preview.gifDurationsMs`；原时长留在 `frames[].durationMs`。例如85ms会预览为90ms。编码器可能合并连续相同画面，因此编码帧数不一定等于源图数。透明像素下不可见RGB不作为WebP保真保证，半透明边缘需在合成底色上检查。

`animation.json` 中：

- `size` 是图集单元尺寸，`rect` 是各帧在图集中的矩形，单位像素。
- `translation` 是源画布到输出单元的 `[dx,dy]`，输出点 = 源点 + 平移。
- `anchor` 是输出单元坐标；未提供锚点时为 `null`，不应在引擎里误当零点。
- `loop` 为动作播放语义；本工具不把单次预览自动改成循环演示。
- `excludedSources` 记录显式去掉的末帧；源姿势、来源标签、身体参考高和命中阶段请另存动作规格。

报告没有“动作已通过”的结论。它不判断走路自然度、角色身份、循环接缝或握点是否正确。最终仍按 [验收清单](quality-and-pitfalls.md) 查看。

## 自检

```bash
python -m unittest discover -s tests -v
```

测试使用自绘简单RGBA图形验证共同坐标、像素保持、锚点平移、帧序、时长、错误输入和目标目录保护。它们不代表某个角色的动作已经通过审核。
